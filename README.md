# Morse Code Translator

A fast and easy Morse Code Translator that converts normal text into Morse code and decodes Morse code back into readable text instantly. This tool is useful for students, developers, radio operators, and Morse code enthusiasts.

🌐 Website: https://justmorsecodetranslator.com/

## Features

* Text to Morse code conversion
* Morse code to text decoding
* Instant real-time translation
* Copy and reset functionality
* Beginner-friendly interface
* Mobile and desktop support
* Supports letters, numbers, and symbols

## Try It Online

Use the live tool here:

https://justmorsecodetranslator.com/

## How It Works

1. Enter text or Morse code
2. The translator instantly processes the input
3. View the translated result in real time
4. Copy or reset the output anytime

## Supported Characters

* A–Z Alphabets
* Numbers 0–9
* Common punctuation symbols
* Spaces and separators

* HTML
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/georgehalbart/morsecodetranslator.git
```

Open the project folder and run it in your browser.

## Usage Example

### Text to Morse

Input:

```text
HELLO
```

Output:

```text
.... . .-.. .-.. ---
```

### Morse to Text

Input:

```text
... --- ...
```

Output:

```text
SOS
```
